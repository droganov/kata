## Agent skills

### Issue tracker

Specs and tickets are local markdown: specs in `docs/specs/`, tickets in `docs/tickets/`, exploration maps in `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default roles, recorded as a ticket's `**Status:**` value. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Decisions

Recorded decisions live in `docs/adr/`, in Decisions so far of `.scratch/training-webapp/map.md` and in the `## Answer` sections of `.scratch/training-webapp/issues/`. Read them before asking the operator anything: a recorded decision is never re-asked. Only the map's Not yet specified is open.
