# 04: Первый выстрел: от Программы до собранного Занятия

**What to build:** Человек открывает список Программ, нажимает на одну и видит собранное Занятие списком Упражнений. Тонкая сквозная дорожка через сервер, сборку и экран. Без входа, без сохранения, без отметок.

**Blocked by:** 01, 02

**Status:** closed

- [x] Программа лежит в таблицах: Блоки, Закрепления, добор, противопоказания
- [x] Каталог читается на сервере при холодном старте изолята и остаётся в памяти
- [x] Серверный роут отдаёт собранное Занятие
- [x] Сборка это чистая функция без ввода-вывода
- [x] На клиент уходят только Упражнения этого Занятия, а не весь каталог
- [x] Экран показывает Занятие, разбитое на пять Блоков, с названием и дозой каждого Упражнения
- [x] Роут остаётся тонким: разобрать запрос, позвать сборку, отдать ответ
