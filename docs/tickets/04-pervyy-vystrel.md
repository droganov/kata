# 04: Первый выстрел: от Программы до собранного Занятия

**What to build:** Человек открывает список Программ, нажимает на одну и видит собранное Занятие списком Упражнений. Тонкая сквозная дорожка через сервер, сборку и экран. Без входа, без сохранения, без отметок.

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] Программа лежит в таблицах: Блоки, Закрепления, добор, противопоказания
- [ ] Каталог читается на сервере при холодном старте изолята и остаётся в памяти
- [ ] Серверный роут отдаёт собранное Занятие
- [ ] Сборка это чистая функция без ввода-вывода
- [ ] На клиент уходят только Упражнения этого Занятия, а не весь каталог
- [ ] Экран показывает Занятие, разбитое на пять Блоков, с названием и дозой каждого Упражнения
- [ ] Роут остаётся тонким: разобрать запрос, позвать сборку, отдать ответ
