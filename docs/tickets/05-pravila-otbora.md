# 05: Правила отбора целиком

**What to build:** Собранное Занятие соответствует Программе, а не случайной выборке. Все правила отбора работают и покрыты тестами на шве сборки.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] Закреплённые Группы мышц присутствуют в каждом Занятии без исключений
- [ ] Внутри Закреплённой Группы мышц Мишень выбирается случайно, затем Упражнение внутри Мишени
- [ ] Добор берёт ровно `count` штук и только из незакреплённого
- [ ] Упражнение, запрещённое противопоказаниями, не появляется ни при каком зерне
- [ ] Фильтр противопоказаний работает до отбора, а не проверкой после сборки
- [ ] Порядок Блоков фиксирован, внутри Блока Закреплённые идут перед Добранными
- [ ] Одинаковое зерно даёт одинаковое Занятие, разные зёрна дают разные
- [ ] Зерно сохраняется вместе с Занятием
- [ ] Одно Упражнение не попадает в Занятие дважды
- [ ] Разминка отдаёт все одиннадцать суставов
- [ ] Растяжка добавляет Мишень под нагруженное сегодня через `block_pair`
- [ ] Тесты покрывают каждый пункт выше и не знают про устройство функции внутри
