# 10: История влияет на сборку

**What to build:** То, что человек делал на прошлой неделе, выпадает заметно реже нового. Каталог при этом не исчерпывается.

**Blocked by:** 05, 09

**Status:** ready-for-agent

- [ ] Лог подаётся на вход сборке вместе с Программой и каталогом
- [ ] Вес считается как `max(d / 21, 0.02)`, где `d` это дни с последнего показа
- [ ] Упражнение, которого нет в логе, имеет полный вес
- [ ] Показанное вчера выпадает существенно реже нового, проверено на большой выборке зёрен
- [ ] При логе, покрывающем весь каталог, сборка всё равно возвращает Занятие
- [ ] Вес Группы мышц и Мишени считается по самому свежему Упражнению из них
- [ ] Мишень «шейный отдел» продолжает отдавать все четыре Упражнения каждое Занятие
