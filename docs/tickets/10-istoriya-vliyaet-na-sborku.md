# 10: История влияет на сборку

**What to build:** То, что человек выполнил на прошлой неделе, выпадает заметно реже нового. Каталог при этом не исчерпывается.

**Blocked by:** 05, 09

**Status:** ready-for-agent

- [ ] История подаётся на вход сборке вместе с Программой и каталогом
- [ ] Вес считается как `max(d / 21, 0.02)`, где `d` это дни с последнего выполнения
- [ ] Упражнение, которого нет в Истории, имеет полный вес
- [ ] Вес решает только случайный выбор: Закреплённые Группы мышц и Мишени попадают в Занятие всегда
- [ ] Выполненное вчера выпадает существенно реже нового, проверено на большой выборке зёрен
- [ ] При Истории, покрывающей весь каталог, сборка всё равно возвращает Занятие
- [ ] Вес Группы мышц и Мишени считается по самому свежему выполненному Упражнению из них
- [ ] Мишень «шейный отдел» продолжает отдавать все четыре Упражнения каждое Занятие
