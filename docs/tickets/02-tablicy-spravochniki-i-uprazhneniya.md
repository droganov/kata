# 02: Таблицы: справочники и упражнения

**What to build:** Четыре каталога упражнений превращаются в плоские таблицы. Группы мышц, Мишени, Оборудование, Упражнения и связи между ними лежат построчно и проверяются критиком.

**Blocked by:** Нет, можно начинать сразу

**Status:** ready-for-agent

- [ ] Конвертер читает `warmup.json`, `strength.json`, `calisthenics.json`, `stretch.json` и пишет таблицы в jsonl
- [ ] Один файл на таблицу, одна строка на кортеж, ключи совпадают с именами столбцов
- [ ] Значения только скалярные: массив или вложенный объект это ошибка конвертации
- [ ] Десять Групп мышц, Мишени с полем вида, включая одиннадцать суставов разминки
- [ ] Каталог как сущность отсутствует: он стал столбцом `exercise.modality`
- [ ] Мишень «широчайшие» существует в одном экземпляре, а не в трёх
- [ ] Все 141 упражнение перенесены, ни одно не потеряно
- [ ] Поля `axis`, `origin` и `slot` в упражнение не попадают
- [ ] Связь упражнения с оборудованием записана один раз, а не в обе стороны
- [ ] У каждого упражнения ровно одно оборудование с ролью `main`
- [ ] Критик проверяет пять правил формата и целостность всех внешних ключей, запускается через `make check`
