# 02: Таблицы: справочники и упражнения

**What to build:** Четыре каталога упражнений превращаются в плоские таблицы. Группы мышц, Мишени, Оборудование, Упражнения и связи между ними лежат построчно и проверяются критиком.

**Blocked by:** Нет, можно начинать сразу

**Status:** done

- [x] Конвертер читает `warmup.json`, `strength.json`, `calisthenics.json`, `stretch.json` и пишет таблицы в jsonl
- [x] Один файл на таблицу, одна строка на кортеж, ключи совпадают с именами столбцов
- [x] Значения только скалярные: массив или вложенный объект это ошибка конвертации
- [x] Десять Групп мышц, Мишени с полем вида, включая одиннадцать суставов разминки
- [x] Каталог как сущность отсутствует: он стал столбцом `exercise.modality`
- [x] Мишень «широчайшие» существует в одном экземпляре, а не в трёх
- [x] Все 408 упражнений перенесены, ни одно не потеряно
- [x] Поля `axis`, `origin` и `slot` в упражнение не попадают
- [x] Связь упражнения с оборудованием записана один раз, а не в обе стороны
- [x] У каждого упражнения ровно одно оборудование с ролью `main`
- [x] Критик проверяет пять правил формата и целостность всех внешних ключей, запускается через `make check`
