# 12: Заглушка входа и Аккаунт

**What to build:** Человек регистрируется и входит. WebAuthn не вызывается, письмо не уходит, код принимается любой, но экраны и форма данных настоящие.

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] Регистрация спрашивает никнейм и почту
- [ ] Код подтверждения запрашивается, в заглушке принимается любой
- [ ] Аккаунт получает постоянный непрозрачный идентификатор на 64 байта
- [ ] Вход держится между запусками приложения
- [ ] Токен Сеанса лежит в куке, которую ставит сервер, а не скрипт
- [ ] Список Сеансов виден, любой гасится по отдельности
- [ ] Есть гашение всех Сеансов кроме текущего
- [ ] При регистрации показано предупреждение, что аккаунт живёт в связке ключей
- [ ] Форма данных совпадает с настоящей: фаза 2 меняет начинку, а не переписывает экраны
