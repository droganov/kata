# 03: Таблицы: процедуры, шаги, оракулы

**What to build:** Процедуры выполнения раскладываются по таблицам без потери структуры. Шаги, их цели, оракулы и строки наблюдений становятся плоскими записями.

**Blocked by:** 02

**Status:** closed

- [x] Шаги привязаны к упражнению и упорядочены
- [x] Поле `active` шага стало связующей таблицей, а не массивом внутри шага
- [x] Оракулы привязаны к шагу и упорядочены
- [x] Списки `model` и `counterModel` лежат в одной таблице с признаком стороны
- [x] Вердикты судьи перенесены и ссылаются на конкретную строку наблюдения
- [x] Цели шага являются подмножеством целей упражнения, критик это проверяет
- [x] Ни один оракул и ни одна строка наблюдения не потеряны при конвертации
