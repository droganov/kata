# 03: Таблицы: процедуры, шаги, оракулы

**What to build:** Процедуры выполнения раскладываются по таблицам без потери структуры. Шаги, их цели, оракулы и строки наблюдений становятся плоскими записями.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Шаги привязаны к упражнению и упорядочены
- [ ] Поле `active` шага стало связующей таблицей, а не массивом внутри шага
- [ ] Оракулы привязаны к шагу и упорядочены
- [ ] Списки `model` и `counterModel` лежат в одной таблице с признаком стороны
- [ ] Вердикты судьи перенесены и ссылаются на конкретную строку наблюдения
- [ ] Цели шага являются подмножеством целей упражнения, критик это проверяет
- [ ] Ни один оракул и ни одна строка наблюдения не потеряны при конвертации
