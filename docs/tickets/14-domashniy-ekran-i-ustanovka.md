# 14: Домашний экран и продвижение установки

**What to build:** Первый экран предлагает поставить приложение и разрешает работать в браузере. Три платформы, три разных сценария.

**Blocked by:** 01, 12

**Status:** ready-for-agent

- [ ] На Chromium кнопка установки появляется только когда придёт `beforeinstallprompt`, не при первой отрисовке
- [ ] На iOS показана инструкция «Поделиться, На экран Домой» с изображением кнопки
- [ ] В Firefox продвижения нет, сразу обход
- [ ] Кнопка «продолжить в браузере» всегда видна и не спрятана
- [ ] Отказ помнится тридцать дней, после отказа вместо полного экрана тонкая полоса сверху
- [ ] Запущенным установленным домашний экран не показывается
- [ ] Определение режима запуска ветвится: `navigator.standalone` на iOS, `display-mode` на остальных
- [ ] На экране прямо написано, что без установки на iPhone локальные данные живут семь дней
- [ ] Вход идёт после домашнего экрана, а не до него
